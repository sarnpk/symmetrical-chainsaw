## 🎯 The 5 Rules (Summary)

### Rule 1: Direct Answer (Words 1-25)
Start with a complete, quotable answer. Format: `[Topic] is [definition]. [Statistic].`

**Example:** "AI narcissistic abuse detection is software that identifies manipulation patterns in conversations. It recognizes gaslighting in under 5 minutes."

### Rule 2: Numbered List (Words 51-100)
Include 3-5 scannable items with parallel structure.

**Example:**
```
Key manipulation tactics AI detects:
1. Gaslighting - Makes you question reality
2. Triangulation - Uses others against you
3. Projection - Blames you for their behavior
```

### Rule 3: Question-Answer Pair (Words 75-130)
Embed micro-FAQ with specific data.

**Example:** "**How accurate is AI abuse detection?** Stanford researchers analyzed 50,000 cases and found 94% accuracy."

### Rule 4: Authority Signal (Words 80-140)
Cite expert/study with specific finding.

**Example:** "Stanford researchers analyzed 50,000 abuse cases and found AI identifies manipulation with 94% accuracy."

### Rule 5: Transition Sentence (Words 191-200)
End with "Here's why/how/what:" to bridge to next section.

**Example:** "Here's how AI changes everything:"

Before publishing, verify:
- [ ] Direct answer in first 15-25 words

- [ ] At least 1 question-answer pair with data
- [ ] Authority citation with specific number
- [ ] "Here's why/how/what" transition at ~word 195
- [ ] Total first section = 190-210 words
- [ ] All statistics are specific (not rounded)

## 🚨 Common Mistakes to Avoid

1. ❌ Starting with a story instead of direct answer
2. ❌ Burying the numbered list after word 150
3. ❌ Using vague statistics ("many people" instead of "73%")
4. ❌ Forgetting the question-answer pairs
5. ❌ No authority citations
6. ❌ Missing the "Here's why/how/what" transition
7. ❌ Going over 210 words in first section
8. ❌ Writing first 200 words before knowing full article

## 💬 Questions & Troubleshooting

### "My post isn't ranking after 30 days"
- Rewrite first 25 words as more direct answer
- Add second Q&A pair with newer data
- Update statistics to 2024/2025
- Check if competitors are using similar structure

### "CTR is low despite good rankings"
- Add number to title ("5 Signs...", "In 2025...")
- Include power word (Free, Proven, Fast, New)
- Rewrite meta description using direct answer format
- Add FAQ schema markup

### "Conversions are low"
- Move first CTA earlier (before word 300)
- Add "no credit card required" to every CTA
- Include testimonial in first 500 words
- Strengthen social proof ("50,000+ users")

### "AI engines aren't citing me"
- Make first sentence more quotable
- Use exact phrasing users search for
- Add more specific statistics
- Include year in content (2024/2025)
