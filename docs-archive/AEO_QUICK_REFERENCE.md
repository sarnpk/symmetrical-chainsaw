# AEO Quick Reference Card

**Print this and keep it next to your desk when writing blog posts**

---

## ✅ The 5 Non-Negotiable Rules (First 200 Words)

### Rule 1: Direct Answer (Words 1-25)
```
[Topic] is [definition in 8-12 words]. [Statistic/benefit].
```
✓ Quotable  
✓ Complete sentence  
✓ Includes number  

---

### Rule 2: Numbered List (Words 51-100)
```
Key [category]:
1. [Item] - [Impact]
2. [Item] - [Impact]
3. [Item] - [Impact]
4. [Item] - [Impact]
5. [Item] - [Impact]
```
✓ 3-5 items  
✓ Parallel structure  
✓ Under 12 words each  

---

### Rule 3: Question-Answer Pair (Words 75-130)
```
**[User's question]?** [Answer with data/timeframe].
```
✓ Bold question  
✓ Specific number  
✓ One sentence  

---

### Rule 4: Authority Signal (Words 80-140)
```
[Expert/Study] [verb] [number] [finding].
```
✓ Real source  
✓ Specific data  
✓ Recent (2020+)  

---

### Rule 5: Transition (Words 191-200)
```
Here's [why/how/what]:
```
✓ Exactly this format  
✓ Colon at end  
✓ Leads to next section  

---

## 🎯 Query Type Cheat Sheet

| Query | First Sentence Format |
|-------|----------------------|
| "What is..." | [Topic] is [definition]. [Prevalence stat]. |
| "How to..." | To [goal], [action] [method]. [Success rate]. |
| "Best..." | The best [solution] for [problem] is [answer]. [Proof]. |
| "Why..." | [Phenomenon] happens because [reason]. [Impact stat]. |
| "Can..." | [Yes/No], [topic] [can/cannot] [outcome]. [Condition]. |
| "Signs of..." | [Topic] shows [number] signs. [% who miss them]. |

| Section | Words | Purpose |
|---------|-------|---------|
| Direct answer | 15-25 | Position zero capture |
| Context | 25-50 | Problem setup |

| Q&A + Authority | 100-140 | Trust signals |
| Bridge | 140-190 | Emotional connection |
| Transition | 191-200 | Section bridge |

---

## ⚠️ Common Mistakes to Avoid

❌ Starting with a story or anecdote  
❌ Burying the answer after 50 words  
❌ Using vague statistics ("many people")  
❌ Lists with inconsistent structure  
❌ No question-answer pairs  
❌ Missing authority citations  
❌ Forgetting the transition sentence  
❌ Going over 210 words in first section

- yes/no, possible, achievable, feasible, attainable

## 📝 Template Sentence Starters

**Direct Answers:**
- "[Topic] is [definition]..."
- "To [goal], [action]..."
- "The best [solution] for [problem] is..."
- "[Phenomenon] happens because..."

**Authority Signals:**
- "Stanford researchers found..."
- "A 2024 study of [number] cases..."
- "Dr. [Name] discovered..."
- "Harvard Medical School analyzed..."

**Question-Answers:**
- "**How long does [process] take?** Most..."
- "**Why does [phenomenon] happen?** Research shows..."
- "**Can [outcome] occur?** Yes, when..."
- "**What causes [problem]?** Studies indicate..."

## 🔥 Emergency Fixes

**If not ranking after 30 days:**

1. Rewrite first 25 words as direct answer
2. Move list to words 60-90
3. Add second Q&A pair
4. Update statistics to 2024/2025
5. Add video/image in first 200 words
6. Strengthen meta description

**If CTR < 5%:**

1. Add number to title
2. Include year in title (2025)
3. Add power word (Free, Proven, Fast)
4. Rewrite meta description as direct answer
5. Add FAQ schema markup

**If conversion < 1%:**

1. Add CTA before word 300
2. Strengthen social proof
3. Add urgency ("50,000+ users")
4. Include "no credit card" copy
5. Add testimonial in first 500 words

## 📱 Mobile Optimization

First 200 words must:
- [ ] Use short paragraphs (2-3 sentences max)
- [ ] Include visual break (list/box) by word 60
- [ ] Bold key phrases for scanning
- [ ] Use numbers instead of words (5 not five)
- [ ] Keep sentences under 20 words

---

## 🎨 Visual Elements (First 200 Words)

Required:
- Numbered or bulleted list
- Bold question-answer pair
- Colored callout box (optional but recommended)

Avoid:
- Large images that push text down
- Multiple CTAs (save for after word 200)
- Long paragraphs (max 4 lines on mobile)

## 🚀 Speed Writing Process

1. **Research (10 min):** Find 2-3 statistics and 1 authority source
2. **Outline (5 min):** Write direct answer + list items
3. **Draft (15 min):** Write first 200 words following template
4. **Edit (10 min):** Verify all 5 rules present
5. **Optimize (5 min):** Check word count, reading level, mobile view

**Total time: 45 minutes per post**
