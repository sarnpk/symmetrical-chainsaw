# AEO Blog Post Template - Reclaim

**Use this template for EVERY blog post to maximize Answer Engine Optimization**

---

## 📝 Pre-Writing Checklist

- [ ] Identify primary target query (e.g., "What is gaslighting")
- [ ] Research 1-2 statistics with sources
- [ ] Find authority citation (study/researcher)
- [ ] List 3-5 key points for numbered list
- [ ] Write direct answer in 15-25 words

---

## 🎯 FIRST 200 WORDS (AEO-Optimized Structure)

### [Your Article Title Here]

**RULE 1: Direct Answer (Words 1-25)**
```
[Topic] is [definition in 8-12 words]. [Key statistic or benefit].
```

**Example:**
Gaslighting is psychological manipulation that makes victims question their own reality. 73% of abuse survivors experienced it.

---

**Context Paragraph (Words 26-50)**
```
[Expand on the problem]. [Why traditional solutions fail]. [Introduce your solution/angle].
```

**Example:**
Most victims don't recognize gaslighting for 7 years because abusers disguise manipulation as concern. Traditional therapy requires months to identify patterns, but AI-powered tools analyze conversations instantly.

---

**RULE 2: Numbered List (Words 51-100)**
```
[Category name] [action verb]:
1. [Item] - [One-word impact]
2. [Item] - [One-word impact]
3. [Item] - [One-word impact]
4. [Item] - [One-word impact]
5. [Item] - [One-word impact]
```

**Example:**
Common gaslighting phrases include:
1. "You're too sensitive" - Invalidation
2. "That never happened" - Denial
3. "You're imagining things" - Confusion
4. "Everyone agrees with me" - Isolation
5. "You're crazy" - Destabilization

---

**RULE 3: Question-Answer Pair (Words 101-130)**
```
**[Question in user's voice]?** [One-sentence answer with specific data/timeframe].
```

**Example:**
**How long does gaslighting take to work?** Psychological studies show reality distortion begins within 3-6 weeks of consistent manipulation.

---

**RULE 4: Semantic Triple - Authority Signal (Words 131-160)**
```
[Expert/Institution] [action verb] [specific finding with number].
```

**Example:**
Harvard Medical School researchers analyzed 12,000 abuse cases and found gaslighting victims lose decision-making confidence within 90 days.

---

**Bridge Paragraph (Words 161-190)**
```
[Elaborate on the problem]. [Add emotional context]. [Set up the transition].
```

**Example:**
The average victim questions their own memory 47 times per day during active gaslighting. This constant self-doubt creates anxiety, depression, and complete dependency on the abuser's version of reality. Breaking free requires recognizing the patterns.

---

**RULE 5: Transition Sentence (Words 191-200)**
```
Here's [why this matters/how this works/what you need to know]:
```

**Example:**
Here's how to identify gaslighting in your own relationships:

## ✅ Quality Checklist (Before Publishing)

### AEO Requirements:
- [ ] Direct answer in first 15-25 words
- [ ] Numbered list appears before word 100
- [ ] At least 1 question-answer pair with data
- [ ] Authority citation (study/expert + specific number)
- [ ] "Here's why/how/what" transition at word ~195
- [ ] Total first section = 190-210 words

### Content Quality:
- [ ] All statistics are specific (not rounded)
- [ ] Reading level: 8th grade or lower (use Hemingway Editor)
- [ ] Every claim has a source
- [ ] At least 3 internal links to Reclaim tools
- [ ] CTA appears within first 500 words
- [ ] Meta description uses direct answer format

### SEO Basics:
- [ ] Title includes target keyword
- [ ] URL slug matches primary query
- [ ] H2 headers answer related questions
- [ ] Alt text on all images
- [ ] Schema markup for FAQ sections

### Conversion Optimization:
- First CTA: Free tool (no signup)
- Second CTA: Free trial (email required)
- Third CTA: Paid features (for serious users)

---

## 📊 Performance Tracking

### Monitor These Metrics:
- Position zero captures (Google Search Console)
- AI engine citations (manual check ChatGPT/Perplexity)
- Click-through rate from search
- Time on page (should be 3+ minutes)
- Conversion rate to free tool
- Email captures from article

### Optimization Triggers:
- If CTR < 5%: Rewrite title and meta description
- If time on page < 2 min: Add more visuals/examples
- If no position zero after 30 days: Rewrite first 200 words
- If conversion < 2%: Strengthen CTAs

---

## 💡 Pro Tips

1. **Write the first 200 words LAST** - After you know the full article content
2. **Test multiple direct answers** - A/B test different first sentences
3. **Update statistics quarterly** - Keep authority signals fresh
4. **Repurpose for social** - The numbered list = perfect Twitter thread
5. **Create FAQ schema** - Turn Q&A pairs into structured data
