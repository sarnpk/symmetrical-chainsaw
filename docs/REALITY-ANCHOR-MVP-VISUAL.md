## 📱 USER JOURNEY

### Morning (5 min)
```
1. Open app
2. See Morning Intention on dashboard
3. Read affirmation: "My only goal is my peace"
4. Click "Mark Complete"
5. 🔥 Streak: 8 days
```

### During Day (As needed)
```
1. Confused or doubting yourself?
2. Open Reality Log
3. Add quick entry:
   - Event: What happened
   - Fact: What exactly happened
   - Trait: What NPD trait
   - Pattern: Is it consistent?

```


## 📋 FIELDS SUMMARY

### Affirmations
- Category (morning, boundary, self-compassion)
- Text

### Morning Intention
- Date
- Affirmation ID
- Completed (yes/no)
- Completed at (timestamp)

### Reality Log
- Date
- Event (1 line)
- Fact (2-3 lines)
- NPD Trait (dropdown)
- Is Consistent (yes/no)
- Pattern Note (optional)
