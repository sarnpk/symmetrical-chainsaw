### 1. **AI-Powered Roleplay**
- AI acts as narcissist based on type (Overt/Covert/Malignant)
- Realistic manipulation tactics
- Responds to your messages
- Adapts to your responses

### 2. **Custom Context**
- Paste real WhatsApp/IMO conversations
- AI learns narcissist's patterns

- Technique identification (Grey Rock, BIFF, etc.)

### 4. **Predict Next Move**

## 🎯 Complete User Journey

### Starting a Session
```
1. Choose narcissist type
2. Select scenario
3. (Optional) Paste custom context
4. Click "Start Simulation"
5. AI sends first message
```

### Practicing
```
1. Read narcissist's message
2. Type your response
3. Get instant feedback
4. See effectiveness rating
5. Continue conversation
```

### Using Predictions
